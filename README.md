# Coupon Clipper

A Python browser automation tool that clips digital coupons from the Buskirk Justice Quality Foods coupon website using Playwright and an existing Chrome login session.

## Features

- Connects to an existing Chrome session.
- Finds available digital coupons.
- Clips coupons automatically.
- Navigates through multiple coupon pages.
- Verifies coupon and page updates before continuing.

## Requirements

- Windows
- Python 3.10 or newer
- Google Chrome
- A store account with access to the digital coupon page
